# Wing-Board
A tactics board for REMATCH, made by BlueWing. (Formerly "REMATCH Tactics".)

## Download
- **Windows:** [Wing-Board-Setup.exe](https://github.com/NinjaBarr/rematch-tactics/releases/latest/download/Wing-Board-Setup.exe)
Windows may say "Windows protected your PC" the first time: click **More info › Run anyway**.
On Mac, the first time: System Settings › Privacy & Security › **Open Anyway**.
The app tells you when a new version is out.
